# 디스코제이 Activity 기획·디자인 명세

Discord Activity 화면(`activity-test/`)의 현재 기획과 디자인 기준이에요.
화면이나 에셋을 바꾸기 전에 이 문서를 먼저 읽고, 바꾼 뒤에는 이 문서도 함께 고쳐 주세요.
코드와 이 문서가 다르면 **코드가 기준**이고, 문서를 코드에 맞게 고쳐야 해요.

마지막 갱신: 2026-10-23 (커밋 `dbf263c` 기준)

## 1. 콘셉트

- **"섬에서 공연하는 DJ K.K."**: 동물의 숲 섬 위에서 DJ K.K.가 팀 공용 재생목록을 틀어 주는 라디오예요.
- 전체 톤은 동물의 숲 너굴폰 앱처럼 크림색 종이, 갈색 글씨, 민트·노랑 강조색이에요.
- 재미 요소는 강아지(K.K.)의 반응과 시간대별 하늘로 표현해요. 기능(재생 조작, 곡 추가·삭제)은 항상 분명하게 보여야 해요.
- 효과음은 넣지 않아요.
- **사내 전용**이에요. 닌텐도 공식 이미지를 쓰기 때문에 팀 밖으로 공개하지 않아요.

## 2. 시간대 (오전·오후·저녁·밤) ⚠️ 가장 자주 틀리는 부분

무대의 하늘과 조명은 **보는 사람 기기의 현재 시각**을 따라요. 기준은 사무실 업무 시간이에요.

| 시간 | 값 (`Sky`) | 화면 |
|---|---|---|
| 05:00 ~ 11:00 | `morning` (오전) | 복숭아빛 하늘, 살짝 노란 빛 |
| 11:00 ~ 18:00 | `day` (오후) | 파란 하늘, 구름, 기본 조명 |
| 18:00 ~ 21:00 | `evening` (저녁·노을) | 주황빛 하늘과 바다, 가로등·등불 켜짐 |
| 21:00 ~ 05:00 | `night` (밤) | 남색 하늘, 별, 가로등·등불 켜짐, K.K. 어둡게 |

- 구현은 `src/components/DjBooth.tsx`의 `skyAt(hour)` **한 곳뿐**이에요. 시간 경계는 여기만 고치세요.
- **예전 기준(05–10 / 10–17 / 17–20 / 20–05)은 더 이상 쓰지 않아요.** 문서나 코드에 남아 있으면 위 표로 고쳐 주세요.
- 1분마다 시각을 다시 확인해요. 재생 상태와는 상관없이 시간만으로 정해져요.
- 개발 미리보기에서는 `?preview&sky=morning|day|evening|night`로 시간대를 고정해서 볼 수 있어요.

### 시간대별 색과 조명 값
`src/styles.css`의 `.booth[data-sky=…]` 규칙에 CSS 변수로 모여 있어요.

| 변수 | 역할 |
|---|---|
| `--sky-top`, `--sky-bottom` | 하늘 그라데이션 |
| `--sea`, `--sea-hi` | 지평선 바다 색 |
| `--scene` | 배경(언덕·나무·꽃)에 거는 filter (노을은 sepia, 밤은 brightness .48) |
| `--tint` | K.K.와 콘솔에 multiply로 곱하는 색. 밤에는 `#767eb6`로 어둡고 푸르게 |
| `--light-l`, `--light-r`, `--light` | K.K. 좌우에 비치는 색 조명과 세기. 밤은 민트·분홍 |
| `--glow` | 조명 효과 세기 (밤일수록 큼) |

- 네온 KK 로고, LED, 가로등·등불 불빛은 **스스로 빛나는 것**이라 어둡게 처리하지 않아요.
- 밤에는 K.K.도 배경과 비슷한 밝기로 어두워져야 해요. K.K.만 밝으면 떠 보여요.

## 4. 무대 (DJ K.K.)

### 캐릭터 이미지

- `assets/dj/build-layers.py`가 가로 1400px로 줄여 4장으로 나눠요 → `public/dj/`

| 레이어 | 역할 |
|---|---|
| `kk-dog.webp` | 콘솔 뒤 K.K. (몸통 아래를 늘려 둬서 움직여도 틈이 안 보임) |

- 레코드 회전은 턴테이블 위치에 맞춘 반짝임(`.sheen`)으로 표현해요.

## 5. 배경 (섬)

- **간결하게 유지해요.** 하늘(그라데이션 + 구름 2개, 밤에는 별 3개), 지평선 바다, 둥글게 휘는 잔디 언덕은 CSS로 그려요.
- 장식은 Nookipedia의 **모여봐요 동물의 숲 공식 아이콘**만 써요. 원본은 `assets/source/scene/`, 다듬은 파일은 `public/scene/`에 있고, `assets/dj/build-scene.py`로 다시 만들어요.

| 아이콘 | 위치 |
|---|---|
| 활엽수 ×3 | 지평선. 밑동은 언덕 뒤로 숨겨요 (바다 위에 떠 보이면 안 돼요). 좌우 반전 금지 (빛 방향이 뒤집혀요) |
| 가로등, 정원 등불 | 오른쪽 / 왼쪽 아래. 저녁·밤에 불빛 켜짐 |
| 진달래·히비스커스 덤불 | 왼쪽 / 오른쪽 아래 구석 |
| 코스모스·바람꽃·튤립·팬지 | 아래 양쪽 구석 |

- **콘솔이 가운데 아래를 가리니까** 장식은 지평선과 양쪽 구석에만 둬요.
- 크기는 무대 높이 단위(`cqh`)로 정해서 화면 크기가 달라도 구도가 같아요.
- 새 장식을 넣을 때는 배경이 진짜 투명한지 먼저 확인해요. 예를 들어 `NH Cedar Tree (South Seasonal)`은 배경이 칠해져 있어서 못 써요.

### Discord 데스크톱 전용 크기 (`.desktop-layout`)
Discord가 넘겨주는 `platform=desktop`일 때만 `<html>`에 `desktop-layout` 클래스가 붙어요(`src/lib/layout-client.ts`). 주소에 platform 값이 없는 단독 미리보기에서는 마우스 환경이면 데스크톱으로 봐요. **모바일 Discord에는 적용하지 않아요.** 휴대폰을 가로로 돌려도 위의 일반 규칙을 따라요.

| 데스크톱 창 상태 | 동작 |
|---|---|
| 크게 펼침 | 재생 카드와 레코드 상자가 창에 맞고, 곡 목록은 카드 안에서 스크롤 |
| 채팅 옆에 띄움 (세로 720px 이하·좁은 창) | 무대가 남는 높이만큼 줄어들고, 평소 멘트 대화창은 숨겨 버튼과 음량을 지켜요 |
| 짧은 팝업 (세로 560px 이하) | 무대 왼쪽, 곡 정보·버튼 오른쪽, 레코드 상자는 아래 |
| 미니 (아주 작은 창) | 작은 무대 + 곡 제목 + 이전·재생·다음 + 음량만. 상단바와 레코드 상자는 숨겨요 |

- 오류나 재인증처럼 **꼭 봐야 하는 멘트**는 `data-attention=true`일 때 숨기지 않고 보여줘요.
- 확인한 크기는 1280×800, 1000×600, 1000×480, 760×430, 600×360, 500×500, 320×180, 320×160이에요.

### 연결 상태 유지 (`src/lib/playback-connection.ts`)
- 재생 상태를 마지막으로 확인한 뒤 **30초**까지는 연결된 것으로 봐요. 한 번 읽기에 실패하거나 실시간 연결이 끊겼다가 다시 붙는 정도로는 화면이 "연결 끊김"으로 깜빡이지 않아요.
- 전체 상태 응답과 실시간 메시지(하트비트 포함)만 이 시간을 갱신해요. 곡 목록만 받는 응답은 갱신하지 않아요.
- 30초가 지나면 조작 버튼을 막아요. 인증·권한 오류는 기다리지 않고 바로 다시 연결을 요청해요.

## 9. 작업 방법

```sh
cd activity-test
npm ci
npm run dev        # http://localhost:5174/?preview
npm run build      # tsc + vite build → dist/
```

- 미리보기 주소에 붙일 수 있는 값
  - `?preview=paused|loading|waiting`: 재생 상태
  - `&sky=morning|day|evening|night`: 시간대
  - `&crowd=0..7`: 접속 인원 수
  - `&toast`, `&error`: 알림과 오류 대화창
- 테스트: 저장소 루트에서 `for f in tests/activity-*.test.mjs; do node "$f"; done` (연결 상태 테스트 포함)
- 화면을 바꾼 뒤에는 최소한 데스크톱(1280×720), 휴대폰(390×844, 320×640), 가로 모드(780×380)와 네 가지 시간대를 확인해요.
