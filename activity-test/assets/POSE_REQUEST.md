# DJ 강아지 포즈 이미지 요청서

Activity 화면의 "강아지 DJ 부스"에 쓸 이미지 목록이에요.
강아지 표정은 원본 사진 그대로 쓰고, 포즈(고개, 몸, 앞발, 모자)만 바꿔요.
기준 이미지는 `../public/dj-original.jpeg`(K.K. 인형 사진)입니다.
완성한 파일은 **`activity-test/public/dj/`** 폴더에 아래 파일명 그대로 넣어주세요.

## 공통 규칙 (모든 이미지)

포즈를 바꿔 끼울 때 캐릭터가 튀거나 크기가 달라 보이지 않도록, 아래 규칙을 꼭 지켜주세요.

1. **같은 캐릭터:** 원본 인형과 같은 강아지예요. 흰 털, 검은 뿔테 안경, 주황색 모자, 목에 건 검은 헤드폰을 유지해 주세요. 사진 같은 인형 질감도 그대로 살려 주세요.
2. **표정 고정:** 모든 이미지에서 얼굴 표정은 원본 사진과 **똑같이** 유지해 주세요. 눈, 안경 속 눈 모양, 입을 바꾸지 마세요. 감정은 고개 각도, 몸짓, 모자, 앞발로만 표현해요.
3. **캔버스:** 1024 × 1024 px, **투명 배경 PNG**로 만들어 주세요.
4. **구도 고정:** 모든 포즈의 카메라 각도(정면, 살짝 위에서 내려다봄)와 캐릭터 크기를 같게 해 주세요.
   - 몸통 중심은 캔버스 가로 가운데(x = 512)에 둬요.
   - 머리 크기는 안경 양끝 폭이 약 300px가 되게 맞춰요.
   - 몸 아래쪽은 y ≈ 900 근처에서 잘려도 돼요. 그 아래는 콘솔이 가려요.
5. **콘솔 빼기:** 포즈 이미지에는 강아지만 그려 주세요. 콘솔은 따로 한 장으로 만들어서 모든 포즈 앞에 겹쳐 쓸 거예요.
6. **넣지 말 것:** 글자, 로고, 음표, Zzz, 물음표, 말풍선, 그림자, 배경. 이런 효과는 코드로 따로 그려요.
7. **확인 방법:** 완성한 이미지를 `idle.png` 위에 50% 투명도로 겹쳐 보세요. 몸통 위치와 머리 크기가 거의 일치하면 됩니다.

## 1단계: 꼭 필요한 이미지 (7장)

| 파일명 | 쓰이는 상황 | 포즈 설명 |
|---|---|---|
| `console.png` | 항상 맨 앞에 깔림 | 원본 사진의 검은 DJ 콘솔만 오려낸 이미지예요. 인형 앞발이 콘솔 위에 걸쳐 있으면 지워 주세요. 왼쪽 빨강 원, 오른쪽 파랑 원(턴테이블)은 그대로 둬요. 캔버스 하단에 놓고, 콘솔 윗면이 y ≈ 640 정도에 오게 해 주세요. |
| `idle.png` | 연결됨, 기본 상태 | 원본과 같은 자세예요. 정면을 보고 몸을 똑바로 세웠어요. |
| `groove-left.png` | 재생 중 (번갈아 표시) | 고개를 왼쪽(보는 사람 기준)으로 15° 정도 기울이고, 몸도 살짝 같은 쪽으로 기울였어요. 신나게 리듬 타는 느낌이에요. |
| `groove-right.png` | 재생 중 (번갈아 표시) | `groove-left.png`를 좌우로 뒤집은 자세예요. 모자 방향 같은 비대칭 부분은 원래대로 유지해 주세요. |
| `sleep.png` | 일시정지 | 고개를 앞으로 푹 숙여 꾸벅 조는 자세예요. 모자가 살짝 앞으로 흘러내렸어요. 표정은 원본 그대로이고, 조는 느낌은 코드의 Zzz 효과로 더해요. |
| `dig.png` | 곡 전환 중 (로딩) | 고개를 숙이고 아래쪽(콘솔 뒤 레코드 상자)을 내려다보며 뒤적이는 자세예요. 한쪽 앞발이 아래로 내려가 있어요. |
| `confused.png` | 연결 끊김, 재생 탭 없음 | 고개를 오른쪽으로 크게(약 25°) 갸웃했어요. "어?" 하는 느낌은 코드의 물음표 효과로 더해요. |

## 2단계: 반응용 이미지 (나중에 있어도 됨)

이 이미지들은 1~2초 동안만 보였다가 원래 상태 이미지로 돌아가요.

| 파일명 | 쓰이는 상황 | 포즈 설명 |
|---|---|---|
| `cheer.png` | 곡 추가 성공 | 두 앞발을 위로 번쩍 들고 환호하는 자세예요. |
| `hat-tip.png` | 곡 추가 성공 (대안) | 한 앞발로 모자 챙을 살짝 들어 인사해요. |
| `scratch.png` | 다음곡, 이전곡 | 오른쪽 앞발(보는 사람 기준 왼쪽)을 앞으로 뻗어 콘솔 왼쪽 빨강 원 위에 올렸어요. 앞발 끝이 `console.png`의 빨강 원 위치에 닿아야 해요. |
| `toss.png` | 곡 삭제 | 한 앞발을 어깨 뒤로 젖혀 무언가를 뒤로 휙 던진 직후 자세예요. 던지는 물건은 그리지 마세요. |
| `wave.png` | 강아지를 탭했을 때 | 한 앞발을 들어 손을 흔드는 자세예요. |
| `headphones.png` | 재생 중 (가끔 나오는 대안) | 목에 걸려 있던 헤드폰을 귀에 쓰고, 한 앞발로 헤드폰을 누르고 있어요. |
| `stretch.png` | 오래 아무 조작이 없을 때 | 두 앞발을 옆으로 쭉 뻗어 기지개를 켜는 자세예요. |

## 이미지 사용 방법 (참고)

- **효과는 코드로:** 음표, Zzz, 물음표, 말풍선, 레코드판 회전은 전부 코드로 그려요.
- **재생 중 동작:** `groove-left` ↔ `groove-right`를 약 0.6초 간격으로 번갈아 보여주고, 전체를 위아래로 살짝 들썩이게 해요.
- **레코드판 위치:** `console.png`의 빨강 원과 파랑 원 자리에 레코드판 그림을 덮어서 돌려요. 원 위치는 받은 이미지에서 제가 직접 잴게요.
- **용량:** 파일당 약 300KB 이하로 줄여 주세요. 크면 제가 WebP로 변환할게요.
