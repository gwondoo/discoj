# 디스코제이 Activity 기획·디자인 명세

Discord Activity 화면(`activity/`)의 현재 기획과 디자인 기준이에요.
화면이나 에셋을 바꾸기 전에 이 문서를 먼저 읽고, 바꾼 뒤에는 이 문서도 함께 고쳐 주세요.
코드와 이 문서가 다르면 **코드가 기준**이고, 문서를 코드에 맞게 고쳐야 해요.

마지막 갱신: 2026-10-26 (동물의 숲 느낌 강화: 너굴폰 시계·리본 제목, 잎사귀 바탕·바느질 카드, K.K. 반응 멘트, 말랑한 버튼, 말풍선 꼬리·제목 강조, 잔디 무늬·나비·반딧불이)

## 1. 콘셉트

- **"섬에서 공연하는 DJ K.K."**: 동물의 숲 섬 위에서 DJ K.K.가 팀 공용 재생목록을 틀어 주는 라디오예요.
- 전체 톤은 동물의 숲 너굴폰 앱처럼 크림색 종이, 갈색 글씨, 민트·노랑 강조색이에요.
- 재미 요소는 강아지(K.K.)의 반응과 시간대별 하늘로 표현해요. 기능(재생 조작, 곡 추가·삭제)은 항상 분명하게 보여야 해요.
- 효과음은 넣지 않아요.
- 이미지는 로컬 전용으로 Git 추적에서 제외하고 이미지 확장자를 `.gitignore`에 넣어요. 새 환경에는 원본과 런타임 이미지를 사내 경로로 따로 복사해요. 현재 파일 추적 해제는 과거 공개 커밋의 이미지를 삭제하지 않아요.
- **사내 전용**이에요. 닌텐도 공식 이미지를 쓰기 때문에 팀 밖으로 공개하지 않아요.

## 2. 시간대 (오전·오후·저녁·밤) ⚠️ 가장 자주 틀리는 부분

무대의 하늘과 조명은 **보는 사람 기기의 현재 시각**을 따라요. 09–18시 근무시간 안에서 네 가지 분위기가 모두 나타나도록 나눴어요. 실제 일출·일몰 시각을 재현하는 기준은 아니에요.

| 시간 | 값 (`Sky`) | 화면 |
|---|---|---|
| 09:00 ~ 11:00 | `morning` (오전) | 진한 복숭아·살구빛 하늘, 따뜻한 빛 (오후와 한눈에 구분돼야 해요) |
| 11:00 ~ 14:00 | `day` (오후) | 파란 하늘, 구름, 기본 조명 |
| 14:00 ~ 16:00 | `evening` (저녁·노을) | 주황빛 하늘과 바다, 가로등·등불 켜짐 |
| 16:00 ~ 다음 날 09:00 | `night` (밤) | 남색 하늘, 별, 가로등·등불 켜짐, K.K. 어둡게 |

- 구현은 `src/components/DjBooth.tsx`의 `skyAt(hour)` **한 곳뿐**이에요. 시간 경계는 여기만 고치세요.
- **근무 중 밤 화면은 16–18시**이며, 퇴근 후부터 다음 날 09시까지도 밤 화면을 유지해요. 이전 시간 경계는 더 이상 쓰지 않아요.
- 1분마다 시각을 다시 확인해요. 재생 상태와는 상관없이 시간만으로 정해져요.
- 개발 미리보기에서는 `?preview&sky=morning|day|evening|night`로 시간대를 고정해서 볼 수 있어요.

### 시간대별 색과 조명 값
`src/styles.css`의 `.booth[data-sky=…]` 규칙에 CSS 변수로 모여 있어요.

| 변수 | 역할 |
|---|---|
| `--sky-top`, `--sky-bottom` | 하늘 그라데이션 |
| `--sea`, `--sea-hi` | 지평선 바다 색 |
| `--scene` | 배경(언덕·나무·꽃)에 거는 filter (노을은 sepia, 밤은 brightness .48) |
| `--tint` | K.K.와 콘솔에 multiply로 곱하는 색. 밤에는 `#767eb6`로 어둡고 푸르게 |
| `--light-l`, `--light-r`, `--light` | K.K. 좌우에 비치는 색 조명과 세기. 밤은 민트·분홍 |
| `--glow` | 조명 효과 세기 (밤일수록 큼) |

- 네온 KK 로고, LED, 가로등·등불 불빛은 **스스로 빛나는 것**이라 어둡게 처리하지 않아요.
- 밤에는 K.K.도 배경과 비슷한 밝기로 어두워져야 해요. K.K.만 밝으면 떠 보여요.

## 3. 화면 구성

```
┌─ 상단바: 로고(잎) · 디스코제이 | 시계(너굴폰 스타일) | 연결 상태 ─┐
├─ 지금 듣는 곡 카드 ─────────────┬─ 레코드 상자 카드 ───────────┤
│ 제목줄: 아이콘 · 제목 | N명 · 상태 │ 제목줄: 아이콘 · 곡 수 | 새로고침 │
│ [무대] 섬 + DJ K.K.               │ [신청] 유튜브 링크 입력 + 신청   │
│ [대화창] K.K. 이름표 + 멘트        │ 곡 목록 (자켓 · 제목 · 배지 · 삭제) │
│ 곡 제목 · 유튜브에서 보기          │ ─ 유튜브 재생목록 열기           │
│ ⏮  ⏯  ⏭                          │                               │
│ 🔈 음량 페이더 (손 떼면 적용)       │                               │
└──────────────────────────────┴──────────────────────────┘
```

| 영역 | 파일 | 기준 |
|---|---|---|
| 무대 | `src/components/DjBooth.tsx` | 아래 4·5절 |
| 대화창 | `src/components/Dialogue.tsx` | 주민 대화창. 주황 "K.K." 이름표, 한 글자씩 타이핑(전체 문장 자리를 미리 잡아 상자 크기가 변하지 않음), 끝나면 ▼ 깜빡임. 오류면 이름표 빨강 |
| 재생 카드 | `src/components/Player.tsx` | 재생/일시정지는 버튼 하나(실제 재생 상태 기준). 음량은 손 떼면 적용 |
| 레코드 상자 | `src/components/Crate.tsx` | 곡마다 영상 썸네일을 자켓에 인쇄한 것처럼 보여줘요(아래 "썸네일 자켓"). 지금 곡은 민트 배경 + 레코드 회전 |
| 삭제 확인 | `src/components/DeleteDialog.tsx` | 대화 선택지 "응, 빼줘" / "아니, 그냥 둘래" |
| 알림 | `src/App.tsx` | 짧은 성공 알림은 위에서 내려오는 너굴폰 알림. 오류는 대화창 |
| 서버 연동 | `src/discoj.ts` | 화면은 `View`만 그려요. 로직은 여기서만 |

### 썸네일 자켓 (`Sleeve`, `src/lib/thumbnail.ts`)
- 자켓은 두 겹이에요. 아래에는 제목으로 색이 정해지는 **기본 자켓**, 위에는 유튜브 **썸네일**(정사각형으로 가운데를 잘라 냄)이 있어요. 레코드 판은 자켓 뒤에서 오른쪽으로 살짝 삐져나와요.
- 상태는 `data-cover`로 나눠요.
  - `loading`: 기본 자켓 위로 빛이 지나가는 반짝임 효과를 보여줘요.
  - `loaded`: 썸네일이 0.3초 동안 서서히 나타나요. 가장자리에 반투명 흰 테두리를 둘러 인쇄한 자켓처럼 보이게 해요.
  - `failed`: 썸네일을 지우고 기본 자켓을 그대로 보여줘요. 영상 ID가 없는 링크, 불러오기 실패, 삭제된 영상(유튜브의 120px 회색 대체 이미지)이 여기에 해당해요.
- 썸네일은 Discord 보안 정책 때문에 `i.ytimg.com`을 직접 부르지 못해요. 그래서 우리 nginx의 `/thumb/<영상ID>`를 거쳐요. 11자리 영상 ID만 받아서 아무 주소나 대신 불러오는 통로가 되지 않게 했어요. 하루 동안 캐시해요. 개발 서버(`vite.config.ts`)에도 같은 경로가 있어요.
- 미리보기 목록의 1·2번 곡은 실제 썸네일, 3번은 없는 영상, 나머지는 ID가 없어서 기본 자켓으로 나와요.

### K.K. 반응 멘트 (`src/discoj.ts`의 `Reaction`)
- 곡을 신청하거나 삭제하면 K.K.가 6초 동안 대화창에서 반응해요. 곡 제목은 `'제목'`으로 감싸고 `--highlight` 주황색으로 강조해요(동물의 숲 대화에서 아이템 이름을 색으로 표시하는 방식이에요).
- 신청 멘트는 세 가지 중 하나를 무작위로 골라요. 삭제 멘트는 "'제목', 상자에서 빼뒀어요. 다음에 또 만나요!"예요.
- 제목 뒤에 조사(은/는, 이/가)를 붙이지 않아요. 제목이 받침으로 끝나는지 알 수 없어서예요.
- 오류 멘트와 서버 끊김 멘트가 반응 멘트보다 먼저 나와요. 짧은 성공 알림(너굴폰 알림)은 그대로 함께 떠요.
- 미리보기에서는 `?preview&react`로 확인해요.

## 5. 배경 (섬)

- **간결하게 유지해요.** 하늘(그라데이션 + 구름 2개, 밤에는 별 3개), 지평선 바다, 둥글게 휘는 잔디 언덕은 CSS로 그려요.
- 장식은 Nookipedia의 **모여봐요 동물의 숲 공식 아이콘**만 써요. 원본은 `assets/source/scene/`, 다듬은 파일은 `public/scene/`에 있고, `assets/dj/build-scene.py`로 다시 만들어요.

| 아이콘 | 위치 |
|---|---|
| 활엽수 ×3 | 지평선. 밑동은 언덕 뒤로 숨겨요 (바다 위에 떠 보이면 안 돼요). 좌우 반전 금지 (빛 방향이 뒤집혀요) |
| 가로등, 정원 등불 | 오른쪽 / 왼쪽 잔디 위(덤불보다 위쪽이라 가려지지 않아요). 저녁·밤에 불빛 켜짐 |
| 진달래·히비스커스 덤불 | 왼쪽 / 오른쪽 아래 구석 |
| 코스모스·튤립 | 콘솔 양옆 잔디 (섬 레이어, 콘솔 뒤) |
| 바람꽃·팬지 | 맨 아래 양쪽 구석, **앞쪽 레이어**(`.foreground`, 콘솔 위). 화면이 좁아 콘솔이 넓어져도 가려지지 않아요 |

- **콘솔이 가운데 아래를 가리니까** 장식은 지평선과 양쪽 구석에만 둬요. 콘솔 폭은 무대 높이를 따라가서, 좁은 화면일수록 무대 폭에서 차지하는 비율이 커져요. 콘솔 뒤 레이어에 둔 장식은 좁은 화면에서 확인하세요.
- 미니 화면에서는 작은 꽃과 앞쪽 레이어를 숨겨요.
- 크기는 무대 높이 단위(`cqh`)로 정해서 화면 크기가 달라도 구도가 같아요.
- 잔디 언덕에는 동물의 숲처럼 작은 **ㅅ자 잔디 무늬**(`--grass-tufts`)와 밝은 점을 깔아요.
- **생물**: 오전·오후에는 노랑·분홍 나비 2마리가, 저녁·밤에는 반딧불이 4마리가 날아다녀요(`.fx .critter`, CSS로 그림). 움직임 줄이기 설정에서는 멈추고, 미니 화면에서는 숨겨요.
- 새 장식을 넣을 때는 배경이 진짜 투명한지 먼저 확인해요. 예를 들어 `NH Cedar Tree (South Seasonal)`은 배경이 칠해져 있어서 못 써요.

## 6. 디자인 시스템 (토큰과 컴포넌트)

토큰은 **`src/tokens.css` 한 곳**에만 정의하고, `src/main.tsx`에서 `styles.css`보다 먼저 불러와요. 컴포넌트 스타일(`src/styles.css`)에는 색·글자 크기·모서리를 숫자로 직접 쓰지 말고 토큰 이름을 써 주세요. 새 값이 필요하면 먼저 `tokens.css`에 이름을 붙여 추가하고 이 표도 고쳐 주세요.
예외는 두 가지예요. 시간대마다 바뀌는 무대 색(`.booth[data-sky=…]`, 2절)과 섬 소품의 그림 색(잔디·음표·별 등)은 장면 그림이라 `styles.css`에 그대로 둬요.

### 색

| 바탕 / 바탕 점무늬 | `--paper` / `--paper-dot` | `#f1e7c8` / `#e7dbb6` |
| 카드 / 안쪽 면 / 구분선 | `--card` / `--inset` / `--line` | `#fffaeb` / `#f5ebcf` / `#eadcb6` |

- `-dark` 색은 그 색 버튼의 **아래 그림자**에 써요. `-soft` 색은 배지나 배경처럼 옅은 면에 써요.

- 다크 모드는 없어요. Discord 안에서도 항상 크림색 종이 화면이에요.

### 글꼴과 글자 크기
- `--display` `Jua`: 제목, 버튼, 배지, 대화창, 숫자. `--body` `Gowun Dodum`: 본문과 입력칸. 두 글꼴 모두 앱에 포함돼 있어 외부에서 불러오지 않아요.
- 크기: `--fs-2xs 11` · `--fs-xs 12` · `--fs-sm 13` · `--fs-md 14`(기본) · `--fs-base 15` · `--fs-lg 17` · `--fs-xl 18` · `--fs-2xl 21`(곡 제목) · `--fs-3xl 26`
- 소품 장식(큰 음표, 물음표)과 작은 창 전용 미세 조정 몇 개만 숫자 크기를 그대로 써요.

### 모양
- 모서리: `--r-sm 12`(로고, 미니 대화창) · `--r-md 18`(곡 목록 줄, 모바일 무대) · `--r-lg 22`(무대, 알림) · `--r-xl 28`(카드) · `--r-pill 999`(배지, 버튼, 입력칸). 동그란 버튼은 `50%`.
- 그림자: 아래로 딱 떨어지는 **통통한 그림자**(`0 Npx 0 var(--shadow 또는 -dark)`)가 기본이에요. 카드는 6px, 큰 버튼은 4–5px, 작은 요소는 1–3px예요. 떠 있는 카드에만 `--drop` 번진 그림자를 더해요.
- 간격과 크기: `--pad`(카드 안쪽), `--gap`(카드 사이), `--head-h`(상단바), `--stage-h`(무대 높이). 반응형 규칙(7절)이 레이아웃마다 이 값을 바꿔요.
- 아이콘: `src/components/icons.tsx`. 크기는 위치마다 `--icon` 변수 하나로 정해요.

### 컴포넌트 규칙
| 컴포넌트 | 클래스 | 규칙 |
|---|---|---|
| 카드 | `.card` | `--card` 면, `--r-xl`, 6px 통통한 그림자 + 번진 그림자, 안쪽 8px에 `--line` 점선 **바느질 테두리** |
| 카드 제목줄 | `.card-head` | 제목은 너굴폰 앱 제목처럼 `--inset` **리본**(오른쪽 끝이 V자로 파임). 배지나 텍스트 버튼은 오른쪽 |
| 시계 | `.clock` | 너굴폰 상태바처럼 `--card` 알약 안에 큰 시각과 날짜. 콜론이 깜빡여요 |
| 상태 배지 | `.state-pill`, `.now-badge`, `.listeners` | 알약 모양. 재생은 민트, 일시정지는 노랑+`--on-yellow`, 곡 불러오는 중은 주황, 연결 대기는 기본(`--inset`·`--ink-soft`) |

| 주 행동 버튼 | `.request button` | 노랑 알약 + `--yellow-dark` 그림자. 그림자만큼 위로 올려 가운데 맞춤 |
| 텍스트 버튼 | `.text-button` | 배경 없음, `--ink-soft`, 터치 환경에서는 높이 40px |
| 대화창 | `.dialogue` + `.nametag` | `--bubble` 면, 울퉁불퉁한 모서리, 위쪽 가운데에 K.K.를 가리키는 **말풍선 꼬리**, 주황 이름표(오류는 빨강). 강조 단어는 `<em>`(`--highlight`). 선택지는 `.choice` |
| 알림 | `.toast` | 위에서 내려오는 너굴폰 알림. 짧은 성공 메시지에만 써요 |
| 음량 바 | `.fader` | `--inset` 알약 안에 민트 채움 + `--track` 빈 부분, 흰 손잡이 |

- 버튼은 아래 그림자가 있는 통통한 모양이에요. **그림자가 있는 버튼은 그림자만큼 위로 올려서 가운데를 맞춰요**(신청 버튼, 재생 버튼).
- **말랑한 버튼**: 누르면 옆으로 퍼지며 눌렸다가(`scale: 1.06 .9`) 손을 떼면 통통 튀며 돌아와요. 마우스를 올리면 동그란 버튼과 신청 버튼이 살짝 흔들려요(`wiggle`, 마우스 환경만). 움직임 줄이기 설정에서는 꺼져요.
- 포커스는 모든 버튼과 입력칸에 민트 3px 테두리(`:focus-visible`)로 보여요.
- 게임 전용 글꼴이나 UI 이미지는 쓰지 않아요.

### 줄바꿈
- 전체에 `word-break: keep-all`을 적용해요. 한국어가 글자 중간이 아니라 **어절 사이**에서 줄바꿈돼요. 링크나 영상 ID처럼 띄어쓰기 없이 긴 문자열은 `overflow-wrap: anywhere`로 끊어서 화면 밖으로 넘치지 않게 해요.
- 제목(`h1–h3`, 삭제 확인 곡 제목)은 `text-wrap: balance`로 줄 길이를 고르게 맞춰요. 본문·목록·곡 제목은 `text-wrap: pretty`로 마지막 줄에 한 단어만 남지 않게 해요.
- 배지, 버튼 문구, 미니 화면 안내처럼 짧은 한 줄짜리는 `white-space: nowrap`으로 유지해요. 넘치면 말줄임(…)이나 줄 수 제한(`line-clamp`)으로 처리해요.

### Discord 데스크톱 전용 크기 (`.desktop-layout`)
Discord가 넘겨주는 `platform=desktop`일 때만 `<html>`에 `desktop-layout` 클래스가 붙어요(`src/lib/layout-client.ts`). 주소에 platform 값이 없는 단독 미리보기에서는 마우스 환경이면 데스크톱으로 봐요. **모바일 Discord에는 적용하지 않아요.** 휴대폰을 가로로 돌려도 위의 일반 규칙을 따라요.

| 데스크톱 창 상태 | 동작 |
|---|---|
| 크게 펼침 | 재생 카드와 레코드 상자가 창에 맞고, 곡 목록은 카드 안에서 스크롤 |
| 채팅 옆에 띄움 (세로 720px 이하·좁은 창) | 무대가 남는 높이만큼 줄어들고, 평소 멘트 대화창은 숨겨 버튼과 음량을 지켜요 |
| 짧은 팝업 (폭 420px 이상 · 세로 560px 이하) | 무대 왼쪽, 곡 정보·버튼 오른쪽(무대 높이 안에서 세로 가운데 정렬), 레코드 상자는 아래 |
| 미니 (아주 작은 창, Discord PIP) | **보기 전용**: 무대 + 상태 배지 + 곡 제목(최대 3줄) + 음량 % + "눌러서 열면 조작할 수 있어요". Discord가 PIP 클릭을 창 복원·이동에 쓰므로 버튼·페이더를 두지 않아요 |

- 오류나 재인증처럼 **꼭 봐야 하는 멘트**는 `data-attention=true`일 때 숨기지 않고 보여줘요.
- 일반 오류에는 즉시 누를 수 있는 **닫기** 버튼을 둬요(미니 모드에서는 누를 수 없으니 숨기고, 창을 키우면 보여요). 인증·권한 만료는 닫기로 우회하지 않고 다시 연결해야 해요.
- 음량은 드래그 중 타이머로 전송하지 않고, 포인터·방향키를 놓을 때 최종 값만 적용해요. 포인터 캡처로 영역 밖에서 놓아도 확정하고, 포인터 취소·예상치 못한 캡처 상실은 전송 없이 미리보기 값을 되돌려요. 접근성 입력은 포커스를 옮길 때도 확정해요.
- 확인한 크기는 1280×800, 1000×600, 1000×480, 760×430, 600×360, 500×500, 320×180, 320×160이에요.

### 연결 상태 유지 (`src/lib/playback-connection.ts`)
- 재생 상태를 마지막으로 확인한 뒤 **30초**까지는 연결된 것으로 봐요. 한 번 읽기에 실패하거나 실시간 연결이 끊겼다가 다시 붙는 정도로는 화면이 "연결 끊김"으로 깜빡이지 않아요.
- 전체 상태 응답과 실시간 메시지(하트비트 포함)만 이 시간을 갱신해요. 곡 목록만 받는 응답은 갱신하지 않아요.
- 30초가 지나면 조작 버튼을 막아요. 인증·권한 오류는 기다리지 않고 바로 다시 연결을 요청해요.

## 9. 작업 방법

```sh
cd activity
npm ci
npm run dev        # http://localhost:5174/?preview
npm run build      # tsc + vite build → dist/
```

- 미리보기 주소에 붙일 수 있는 값
  - `?preview=paused|loading|waiting`: 재생 상태
  - `&sky=morning|day|evening|night`: 시간대
  - `&crowd=0..7`: 접속 인원 수
  - `&toast`, `&error`: 알림과 오류 대화창
- 테스트: 저장소 루트에서 `for f in tests/activity-*.test.mjs; do node "$f"; done` (연결 상태 테스트 포함)
- 화면을 바꾼 뒤에는 최소한 데스크톱(1280×720), 휴대폰(390×844, 320×640), 가로 모드(780×380)와 네 가지 시간대를 확인해요.

### 운영 경로 정리 (2026-10-26)
- UI 폴더는 `activity/`, Compose 파일은 `compose.activity.yaml`이에요.
- 기존 실행 중인 바인드 마운트를 위해 루트 `activity-test/`에 Git에서 제외한 배포 복사본을 유지해요. 빌드 후 자동으로 동기화해요.
- 컨테이너 표시 이름은 `discoj-activity`, `discoj-activity-tunnel`이에요. Docker 내부 프로젝트 ID는 기존 연결 보존을 위해 유지해요.
- 디자인 반영은 `activity/`에서 빌드만 수행하고, 실행 중인 터널은 재시작하지 않아요.

### 무중단 배포 경로 (2026-10-26)
- Compose도 운영 배포 경로 `activity-test/dist`, `activity-test/nginx.conf`를 사용해 소스 경로와 분리해요.
- 빌드는 배포 폴더를 자동 생성하고 dist와 Nginx 설정을 동기화해요. 설정은 파일 inode를 유지해 쓰고 검증 후 graceful reload하며, 검증 실패 시 이전 설정을 복원해요.
- 시작은 `sh scripts/start-activity.sh`로 실행해요. `--no-recreate`로 기존 웹 서버와 임시 터널을 유지하며, 새로운 환경에서는 서비스를 생성해요.

- Docker Desktop가 경로 변경 후 새 하위 파일을 놓치는 경우를 방지하도록 배포 하위 폴더를 준비한 뒤 교체하고, 이전 해시 자산을 보존해요. HTML은 의존 파일을 준비한 뒤 마지막으로 반영해요.
