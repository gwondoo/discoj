# 디스코제이 개인정보처리방침

시행일: 2026-10-22

## 1. 서비스와 운영자

디스코제이(DiscoJ)는 Lab4DX의 사내 Discord 추천곡 채널과 회사의 공용 YouTube 재생목록을 연결하는 봇입니다. 운영 및 개인정보 관련 문의는 lab4dx@gmail.com 또는 사내 Discord 관리자에게 할 수 있습니다.

## 2. 처리하는 정보와 목적

- Discord 사용자 ID: 봇 계정 및 추가 제외 계정 여부를 확인하며, 곡별 사용자 연결 정보는 저장하지 않습니다.
- 명령어 인수(YouTube 영상 링크, 목록 페이지, 삭제할 항목 ID): 요청한 추가·조회·제거 기능을 처리합니다.
- Discord 서버·채널 ID: 지정 채널에서만 요청을 처리합니다. 삭제 시 관리자 권한은 검사하지 않습니다.
- YouTube 영상 ID·제목·재생목록 항목 ID: 실제 공용 목록 조회, 중복 확인, 추가 및 제거에 사용합니다.
- 운영용 Google OAuth 클라이언트 정보, 액세스 토큰, 리프레시 토큰: 회사 계정이 승인한 YouTube API 요청과 인증 갱신에 사용합니다. 계정 비밀번호는 수집하지 않습니다.

팀원의 Google 계정 연결, 일반 채팅 전체 수집, 광고 프로파일링, 실제 음악 청취 여부나 재생 위치 추적은 하지 않습니다.

## 3. 저장 위치와 보관

- 곡별 추천자 사용자 ID 연결 정보는 저장하지 않습니다.
- 방금 추가한 영상의 중복 방지 정보는 메모리에 보관하고, 60초가 지난 정보는 다음 추천 처리 시 정리합니다. 프로세스 종료 시 사라집니다.
- 액세스 토큰은 만료 전까지 메모리에서 사용합니다. 클라이언트 시크릿과 리프레시 토큰은 운영 기기의 접근이 제한된 로컬 환경설정 파일에 보관하며 공개 저장소에 올리지 않습니다.
- 실제 재생목록은 YouTube에 저장됩니다. 프로세스를 종료하거나 Google 연결을 해제해도 목록은 자동 삭제되지 않습니다.
- 명령어와 봇 응답은 Discord 채널에 남을 수 있으며, Discord의 보관·삭제 기능 및 정책을 따릅니다. 서버 운영 로그에는 연결 상태와 오류 유형이 기록될 수 있습니다.

## 4. 외부 서비스와 공개 범위

디스코제이는 Discord API와 YouTube Data API를 사용합니다. Google에는 영상·재생목록 식별자와 인증 정보가 전송되며, 추천자의 Discord 사용자 ID를 재생목록 데이터에 기록하지 않습니다. 목록 조회 결과 및 요청 결과는 Discord에 표시됩니다.

공용 목록은 일부 공개로 운영하므로 링크를 가진 사람은 목록을 열고 공유할 수 있습니다. 민감한 정보를 추천 링크나 채널 메시지에 넣지 마세요.

- [Google 개인정보처리방침](https://policies.google.com/privacy)
- [Discord 개인정보처리방침](https://discord.com/privacy)
- [YouTube API 서비스 약관](https://developers.google.com/youtube/terms/api-services-terms-of-service)

Google API로 얻은 정보는 요청한 재생목록 기능 제공에만 사용합니다. 이를 판매하거나 광고·AI 모델 학습에 사용하지 않으며, Google API 서비스 사용자 데이터 정책의 제한적 사용 요구사항을 준수합니다.

## 5. 연결 해제와 삭제 요청

운영 계정은 [Google 계정의 연결 관리](https://myaccount.google.com/connections)에서 디스코제이 접근 권한을 철회할 수 있습니다. 운영 담당자에게 요청하면 로컬에 저장된 OAuth 인증 정보를 제거하고 봇을 중지할 수 있습니다.

팀원은 `/삭제 번호`로 모든 재생목록 항목을 제거할 수 있습니다. 원본 영상은 삭제하지 않습니다. Discord에 남은 메시지는 별도로 삭제해야 합니다.

## 6. 변경 안내

처리 항목이나 목적에 변경이 있으면 이 문서의 시행일과 내용을 갱신하고, 사내 운영 채널을 통해 안내합니다.

- 짧은 곡 번호의 재사용을 방지하기 위해 마지막 번호와 YouTube 재생목록 항목 ID 연결을 운영 기기의 JSON 파일에 보관합니다. 이 번호 파일에는 Discord 사용자 ID를 저장하지 않으며, 컨테이너 재시작 후에도 유지됩니다.

- API 한도 초과 시 해제 시각만 `data/quota-state.json`에 보관합니다. 자동완성용 번호·영상 제목은 프로세스 메모리에 짧게 캐시하며 Discord 사용자별 검색어는 저장하지 않습니다.

- 현재곡 기능: 사용자가 연결한 유튜브 탭의 영상 제목·영상 ID·재생 상태를 로컬 봇에 전달합니다. 봇은 최신 정보만 메모리에 보관하며 디스코드 `/현재곡` 응답은 실행한 사용자에게만 표시합니다. 마지막 보고 후 45초가 지나면 표시하지 않으며, 외부 브라우징 기록이나 사용자 Google 인증 정보는 확장에서 수집하지 않습니다.

- 재생 위치 복원: 선택한 재생 탭의 영상 ID, 공용 재생목록 ID, 현재 영상 앞에 있던 영상 ID와 다음곡 대기 여부를 확장 로컬 저장소에 보관합니다. 재연결 시에만 해당 영상과 목록이 일치하는 기록을 사용하며 선택한 탭을 닫으면 삭제합니다.
