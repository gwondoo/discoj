# 디스코제이 이용 안내

시행일: 2026-10-22

## 용도와 대상

디스코제이는 Lab4DX 사내 구성원이 공용 YouTube 재생목록을 관리하기 위한 도구입니다. 별도 이용료나 유료 구독 기능은 없습니다.

## 사용 방법

- 지정 Discord 채널에서 `/추가`, `/목록`, `/삭제` 명령어를 사용합니다.
- 유튜브 영상 링크만 추천할 수 있고, 동일 영상이 목록에 있으면 중복 추가하지 않습니다.
- 개인 추천 횟수 제한은 없습니다. 목록 크기 제한과 YouTube API 할당량에 따라 요청이 중단될 수 있습니다.
- 본인 추천 항목만 삭제할 수 있습니다. 운영자는 모든 항목을 제거할 수 있고, 재시작 전 추천자 정보가 사라진 항목은 관리자에게 삭제를 요청해야 합니다.
- 음악 재생은 YouTube에서 진행합니다. 봇은 재생 상태나 다음 곡 전환을 제어하지 않습니다.

## 이용 시 유의사항

업무 환경에 적합한 콘텐츠를 추천하고, 타인의 권리와 사내 운영 기준을 존중해주세요. YouTube 이용 시 [YouTube 서비스 약관](https://www.youtube.com/t/terms)이 적용되며, Discord 이용에는 Discord의 약관과 정책이 적용됩니다. 디스코제이는 콘텐츠에 대한 별도의 이용·배포 권한을 부여하지 않습니다.

네트워크, 인증 만료, API 할당량, 비공개·삭제 영상 등으로 요청이 실패할 수 있습니다. 결과가 불확실하면 `/목록` 또는 YouTube 페이지에서 확인하세요. 삭제는 재생목록 항목 제거이며 원본 영상 삭제가 아닙니다.

운영 기기 재시작 시 메모리의 추천자 연결 정보는 초기화됩니다. YouTube 목록과 Discord 메시지는 각 서비스에 별도로 남습니다. 관리자에 의한 YouTube 직접 편집은 봇 요청과 동시에 일어날 수 있습니다.
