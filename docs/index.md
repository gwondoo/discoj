# 디스코제이 (DiscoJ)

디스코제이는 Lab4DX 사내 Discord 채널에서 팀원들이 추천한 YouTube 영상을 공용 재생목록에 모으는 봇입니다. 일반 대중을 대상으로 계정을 모집하거나 판매하는 서비스가 아닙니다.

## 제공 기능

- `/추가 링크`: YouTube 영상 링크를 지정된 공용 재생목록에 추가합니다.
- `/목록`: 본인에게만 곡 번호와 영상 제목을 표시합니다. 하단 버튼으로 YouTube 재생목록을 엽니다.
- `/현재곡`: 연결된 유튜브 탭의 영상 제목과 링크를 본인에게만 표시합니다.
- `/삭제 번호`: 곡 번호로 목록에서 제거합니다. 지정 채널에서는 누구나 모든 곡을 삭제할 수 있습니다.

음악은 YouTube의 재생목록 페이지에서 재생합니다. 디스코제이는 음원을 다운로드·추출하거나 Discord 음성 채널에 송출하지 않습니다. 자동 음악 전환은 제공하지 않습니다. 선택한 브라우저 탭의 영상 제목과 재생 상태만 연결하며, 긴 영상 내부의 개별 노래는 추적하지 않습니다.

## Google 계정 연결

재생목록 소유 회사 계정 한 개를 운영자가 Google OAuth로 연결합니다. Discord에서 곡을 추천하는 팀원들은 자신의 Google 계정을 연결하지 않습니다. 앱이 요청하는 YouTube 계정 관리 권한은 특정 목록 하나보다 넓지만, 운영 코드는 설정된 공용 재생목록의 조회·추가·제거에만 사용합니다.
