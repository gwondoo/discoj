# DiscoJ · 디스코제이

디스코드에서 유튜브 곡을 접수하고 맥미니 브라우저에서 스피커로 재생하는 서비스.
Python + FastAPI + discord.py, 단일 프로세스의 메모리 대기열을 사용합니다. 별도 관리자 페이지는 없습니다.

## 로컬 실행

Python 3.9 이상(배포는 3.12).

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn discoj.main:app --host 127.0.0.1 --port 8000 --workers 1
```

맥미니 브라우저에서 **http://127.0.0.1:8000** 을 열고 `재생 시작`을 누릅니다. 다른 주소로 접근한다면 `PLAYER_ORIGIN`도 정확하게 맞추세요. 페이지는 재생만 담당하며 곡 관리는 디스코드에서 합니다.

## Discord 설정

1. Discord Developer Portal에서 봇을 생성합니다.
2. OAuth2 URL Generator에서 `bot`, `applications.commands` 선택.
3. 채널 보기, 메시지 보내기, 링크 임베드, 메시지 기록 보기 권한을 부여합니다. 현황 메시지 자동 고정은 메시지 관리 권한도 필요합니다(없어도 나머지 기능 동작).
4. **test 서버**로 초대하고 `.env`에 `DISCORD_TOKEN`을 설정합니다. Message Content/Members/Presence privileged intent는 필요 없습니다.
5. 예제에 들어 있는 테스트 서버·채널 ID를 확인하고 서버를 실행합니다. 명령어는 지정 서버에만 동기화됩니다.
6. 운영 전 `EXCLUDED_USER_IDS`에 lab4dx의 **숫자 사용자 ID**를 넣으세요. 표시 이름으로는 제외하지 않습니다.
7. `FALLBACK_VIDEO_ID`에 카페 음악 영상의 11자리 ID를 지정합니다. 비어 있으면 곡이 없을 때 조용히 대기합니다.

봇 토큰이 비어 있으면 웹 서버만 실행됩니다. 인증 실패는 로그와 `/health`에서 확인합니다. 비밀 값은 `.env`에만 저장하고 커밋하지 마세요.

## 명령어와 정책

| 명령어 | 동작 |
| --- | --- |
| `/추천 링크` | YouTube 영상 하나 접수. 동일 영상 중복 제외 |
| `/목록` | 현재 곡과 앞 10개 대기곡 표시 |
| `/현재곡` | 실제 플레이어 상태와 곡 표시 |
| `/내추천` | 자신의 현재·대기곡 표시 |
| `/삭제 곡번호` | 본인 곡 삭제. 관리자는 모든 곡 삭제 가능 |
| `/도움말` | 사용법 표시 |

- 개인·일일 추천 제한 없음. 잠정 상한은 현재 포함 100곡(`MAX_QUEUE_SIZE`). 기존 90곡 API 제한은 적용하지 않습니다.
- FIFO. 현재 곡 삭제는 다음 곡으로 전환. 카페 음악 중 추천은 즉시 추천곡으로 전환.
- 추천곡이 소진되면 카페 음악 재생. 기본 영상이 끝나면 다시 재생하지만 오류 발생 시 무한 재시도하지 않습니다.
- 일반 영상 오류는 다음 곡으로 건너뜁니다. 자동재생 차단은 대기 상태로 표시합니다.
- 메모리는 날짜에 따라 비우지 않고 완료·삭제된 곡을 제거합니다. 미재생곡은 유지되며 프로세스 재시작 시 전체 초기화됩니다.
- 봇 활동 상태와 현황 메시지는 실제 플레이어 보고를 기준으로 최대 약 5초 간격 갱신. 기존 현황 메시지를 최근 50개에서 찾아 재사용합니다.
- 영상 제목은 재생 후 플레이어에서 확인. 대기 중에는 영상 ID가 표시됩니다. YouTube Data API나 Google OAuth는 사용하지 않습니다.
- 플레이어 한 대만 연결. 연결 끊김은 offline 표시. 재접속 후 시작 버튼을 누르면 현재 곡 처음부터 재생합니다.
- 관리자용 건너뛰기·정지 명령과 예약 초기화는 구현 범위에서 제외했습니다.

## 맥미니 Docker

```sh
docker compose up -d --build
```

Docker는 서버만 실행합니다. 로그인된 macOS 브라우저를 별도로 열어야 소리가 납니다. 포트는 **로컬 기기에만** 공개합니다. 여러 워커나 복제 컨테이너를 실행하면 메모리가 분리되므로 워커는 하나로 유지하세요.

## 검증

```sh
pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

대기열 중복·동시 요청·FIFO·삭제 권한·세션 이벤트·WebSocket 연결을 로컬 테스트합니다.
실제 Discord 연결, YouTube 재생, 자동재생 차단, macOS 기본/블루투스 출력은 현장 검증이 필요합니다. YouTube 광고와 외부 재생 제한은 적용됩니다.
